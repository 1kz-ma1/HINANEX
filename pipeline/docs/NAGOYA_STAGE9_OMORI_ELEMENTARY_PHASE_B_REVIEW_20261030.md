## 2. 限定的に整合した根拠

- **学校一覧掲載**: 名古屋市公式一覧に「大森小学校」が掲載されるとの観察は整合。ただし**所在地の全文と郵便番号をレビュアーが文字列で独立照合した証跡はない**。
- **災害時の関連設備種別**: 仮設トイレと地下式給水栓の表示・凡例を確認した旨の申告が先行報告と整合。ただし設備ごとのレコード同定、設置点、学校建物／入口との関係、災害時の開設は証明していない。
- **学校公式サイト**: トップと学校紹介ページを本人が閲覧した旨の申告。**本文の特定記述・更新日・位置の逐語照合は未記録**。
- **校地・校舎配置図**: 双方「未発見」で整合。先行報告の旧版にあった「発見」の申告は先行班員の訂正版で撤回済み。
- **Phase Bの実質的な矛盾**: 比較対象の範囲で明確なものは報告されていない。ただし**根拠不足を一致へ補完しない**。

公開一次資料の位置情報を地理参照点と同一視せず、関連設備マーカーを学校代表点・入口として採用しない。
