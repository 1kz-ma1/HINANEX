## 2. Phase B比較の確認点

- Phase Aで名称・所在地の**何の文字列を人間が実際に確認したか**。見たというだけで住所全文・更新日値の一致を補わない。
- 施設の1階・2階の平面図は**内部の部屋配置**を示すもので、校地・敷地境界・入口の地理位置ではないか。
- 「周辺地図」「外観写真」は**公式に掲載されていても**、建物位置の精度・撮影時点・方位・地図ピンの意味まで確定できるか。
- 上下水道局の設備エントリと施設管理者の建物情報が同じ地点を指すか**未確定**。名称類似だけで自動一致させない。別施設（平針北コミセン等）との取り違えがないか注意。
- Phase Aと本書が異なる場合、どちらかを即座に正解とせず、**原本の版／対象／確認者／検索条件**を記録し、未解決ならHOLD。
- 同じ自治体内の複数掲載を地理的に独立な位置根拠と数えない。
