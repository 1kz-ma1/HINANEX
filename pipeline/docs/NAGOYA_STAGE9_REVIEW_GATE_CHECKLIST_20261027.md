## 7施設分の個別調査ルール

Stage8報告で敷地外に見えた4件と敷地内に見えた3件を、同じ基準で確認する。

- [ ] 市の公式施設一覧などから、原資料の施設名・住所・種類・版を照合する。
- [ ] 一次資料は「施設同一性」「室内平面図」「校舎配置図」「敷地図」「周辺地図」「入口案内」「関連設備」のどれかを明示する。
- [ ] 室内平面図と周辺地図だけで敷地境界・入口を認定しない。
- [ ] 施設とは別の設備、複数校舎・別敷地、同名別施設の位置を混同しない。
- [ ] 航空写真の時期、資料改訂日、出典が循環していないことを確認する。
- [ ] ABR/GSI参照点との比較は元PRIVATE台帳をローカルで開いて人間が行う。参照点は変更しない。
- [ ] 判断不能の場合は根拠不足の理由を記録し、HOLDを維持する。

既にABR参照点の取得工程と粗い座標精度が分かった2件は、同じ位置確認ゲートに保留のまま残す。原因の技術調査完了を施設の位置受入と混同しない。
