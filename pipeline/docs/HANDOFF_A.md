# A担当への引き渡し — Data Research / Evidence

Aの役割は「評価」ではなく、公式ソースから確認できる事実とEvidenceを揃えることです。

## Dへ渡してほしい情報

- 地域名 / 地域コード
- データ項目名
- 公式ページURL
- 実データURL
- 公開主体
- 更新日 / 公開日
- ファイル形式
- ライセンス
- 列名や凡例の意味
- 欠損・注意事項

## 重要ルール

- 見つからない場合は「存在しない」と断定しない。
- PDF、CSV、Excel等で複数の公式ソースがある場合は両方残す。
- 列名だけで意味を推測しない。凡例や説明ページを確認する。
- 自治体の良し悪しを評価しない。

## Adapter追加時

Aが新規ソースを発見したら、Dは `SourceAdapter` を追加して共通Schemaへ正規化します。A自身がPython実装する必要はありません。
