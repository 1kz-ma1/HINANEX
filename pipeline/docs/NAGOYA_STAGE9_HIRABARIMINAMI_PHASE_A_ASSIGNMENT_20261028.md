# HINANEX Stage 9｜平針南コミュニティセンター Phase A 独立調査依頼

作成: 2026-10-28 / 区分: **班員への配布用** / 結果: **未提出・未判定**

## 目的

名古屋市天白区の**平針南コミュニティセンター**について、施設の公式所在地、施設種別、建物／敷地／入口の根拠、関連する防災設備の根拠を、**先行調査を見ない状態**で公式一次資料から探索・記録する。

この段階では**Phase Bの比較も位置照合L2も実施しない**。最初の調査者が利用した資料や前回の調査結果が同じリポジトリに存在しても、Phase A確定前に開かない。

## AIに貼り付ける依頼文

> あなたは災害時の避難判断を支援するHINANEXの一次資料調査AIです。
>
> 対象は「名古屋市天白区 平針南コミュニティセンター」です。これは**Phase A独立調査**です。
> 他のHINANEX Stage9報告書、過去の調査ログ、比較報告、PRの関連コメントは**Phase A確定まで参照しない**でください。まず名古屋市・天白区・施設管理者の**公開一次資料**を自分で検索・閲覧し、次の項目を記録してください。
>
> 1. 施設の公式名称、所在地、施設種別を明記した資料。
> 2. 施設の外観、室内平面図、周辺地図、敷地図、建物配置図、入口案内があるか。**資料の示す対象と位置の証拠能力を区別**すること。
> 3. 同じ名称が他の部署の災害設備一覧などに登場する場合、そこが施設本体なのか別の設備なのか。**同名という理由で同じ所在地／座標と決めつけない**こと。
> 4. 公式出典URL、発行者、ページ更新日／資料作成日、**実際に本文・図を開いて確認した事実**、確認不能箇所。
> 5. 敷地・建物・入口の正確な位置を示す独立証拠があるか。なければ「未発見」または「未確認」と記録し、存在しないと断定しない。
>
> **禁止**：PRIVATE台帳や候補生座標・個別ID・比較画像の入力／外部送信、施設座標の推定・生成・補正、AIによる位置承認、避難経路／避難適合性／開設状態の推定、GIS・RegionExportへの反映、Phase A確定前の先行報告閲覧。
>
> **提出**：下の記録欄を使いMarkdownで作成。AIが閲覧した資料、人間が自分で閲覧した資料、検索結果しか見られない資料を厳密に分ける。Phase Aを人間が明示的に確定するまでPhase Bへ進まない。

## 班員と取りまとめの手順

1. 班員は**この指示文だけ**を新規AIチャットへ投入して、公式資料を独立に探索する。
2. 班員本人が開いたURL・本文箇所を確認し、**本人が実際に見ていない内容は「AIのみ」**と区別する。
3. Phase Aの結果を独立ファイルに保存し、必要な範囲で人間が「Phase Aを確定」と明言する。
4. **確定後に限り**先行調査の資料を初めて開いてPhase B比較を実施する。
5. Phase B比較所見の人間採用と、L2での座標の位置照合・L3正式位置受入・L4 GIS公開は**別工程**。
