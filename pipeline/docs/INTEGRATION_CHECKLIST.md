# Integration Checklist

他担当の成果をmainへ統合するときの確認表です。

## 共通

- [ ] PRの目的が1つにまとまっている
- [ ] CIが成功している
- [ ] 既存Dテストが全件成功する
- [ ] 秘密情報・個人情報・ローカルパスをコミットしていない
- [ ] 大容量Rawデータを不用意にコミットしていない

## Aを統合するとき

- [ ] 公式ソースURLと公開主体が記録されている
- [ ] 更新日/形式/ライセンスが可能な範囲で記録されている
- [ ] NOT_FOUNDを未公開と断定していない
- [ ] Adapterで推測値を生成していない

## Bを統合するとき

- [ ] RegionExportだけに依存し自治体固有形式へ依存していない
- [ ] `null != 0` をUIで保持している
- [ ] UNKNOWN / INVESTIGATIONを過度にネガティブ表示していない

## Cを統合するとき

- [ ] human judgmentの根拠が残っている
- [ ] 誤判定の場合、再現可能なテストケースが追加されている
- [ ] ルール変更は他2地域への回帰影響を確認している

## Eを統合するとき

- [ ] 座標nullを安全に扱える
- [ ] 推定座標と公式座標を混同していない
- [ ] 地図から除外したrecord数が追跡可能
