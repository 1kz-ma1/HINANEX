**担当:** A / Data Research — **状態: WEB SOURCE CANDIDATE REVIEW ONLY / 未アーカイブ・C未承認・歴史再現未実行**

関連：[設計PR #143](https://github.com/1kz-ma1/HINANEX/pull/143) / [全体Issue #142](https://github.com/1kz-ma1/HINANEX/issues/142) / [基礎受入 #89](https://github.com/1kz-ma1/HINANEX/issues/89) / [施設同一性 #134](https://github.com/1kz-ma1/HINANEX/issues/134)。

本調査は、**2019年の正しい入力と独立の事後結果を区別できるか**を調べるもの。予測モデルの評価、施設の洪水適合性、開設中かどうかのリアルタイム判定を行わない。以下の数値は公式ページの公開内容を2026-10-13に閲覧した**初期候補**。原本のバイト列・履歴・著作権/再利用条件・行政側の修正履歴をA/Cがまだ検証していない。

機械可読の**候補メタデータのみ**を [`2019-typhoon19-edogawa-source-candidates.json`](2019-typhoon19-edogawa-source-candidates.json) に保存した。**rawではない**。ハッシュ未確認値は全て `null`、後から値を創作して埋めない。JSON内の発行日時はページ記載の時刻を転記したもので、実際のWeb配信開始時刻の暗号学的証明ではない。

## 1. まず重要な結論

**調査結果：区単位の「開設施設数の時間変化」は独立した公式観測候補が複数存在する。施設単位の運用実績の候補PDFもある。一方、当時の公表済み入力一式・同一施設の識別・評価分母の承認は未完了。**

- **T0 Source → Outputの追跡**：現行HINANEXのSource照合機構で提示できる可能性があるが、2019年版に同一モデルを適用した検証ではない。
- **T1 施設開設の運用再現（区の集計件数）**：時点別の公式速報を先行評価対象にできる候補。ただし、現在のD洪水Scenarioは開設施設数を将来予測するエンジンではないため**予測精度を主張しない**。
- **T1 施設ごとの照合**：事後の学校記録には施設名等があるが、2019年の当時版マスター／開設時刻／現行D施設との同一性は未承認。2026年の施設名と似ていてもjoin禁止。
- **T2 洪水の空間的影響**：この調査では実被害・浸水と施設対応の独立した比較基準を確定できていない。対象外。

## 5. デモ導線に向けた実装判断（提案、実装ではない）

- **中間発表の確実な見せ場**: 時点ごとの公式公表記録（48 / 73 / 98）と事後総数105を、**異なる定義のデータとして注記したうえで**示す。現行GISのSource追跡・UNKNOWNの実例と組み合わせる。「予測成功」を演出しない。
- **P1後の最初の評価target候補**: 江戸川区の`opened_shelter_count`を指定時刻における公式速報の集計値と照合する区単位T1。ただし**Dにそのtargetを予測する機能は未実装**。安易な線形外挿をHINANEXの正規シミュレーションとして混ぜない。
- **成功ケース**: 入力固定後にD出力と独立実績が事前ルールで一致した場合だけCがMATCH。
- **保留ケース**: 当時の施設ID版・公式記号・データの時点が欠けている場合、ABSTAIN（正誤比較不能はNOT_EVALUABLE）。
- **不一致ケース**: C承認済みの比較対象が実際に食い違った場合のみMISMATCH。故意に値を改変した異常系テストは**システムの異常検知テスト**であり、実災害予測の失敗例ではない。
- **少なくとも3件の検証パターンが実データで揃わない場合**: 発表画面は「未検証」状態を正直に表示し、検証可能なT0の成功と実際のUNKNOWNだけを見せる。未実装のHistorical Replayを「完成機能」としない。
