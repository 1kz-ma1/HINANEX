# HINANEX Gemini Instructions

The canonical repository instructions are in `/AGENTS.md`.

Read `/AGENTS.md` before making any change, then read any nested `AGENTS.md` in the target directory.

Do not:

- push or merge directly to `main`
- bypass the Merge Captain
- infer missing disaster data
- silently break shared contracts
- confuse `null` with zero
- merge dependent PRs out of order

Report changed files, contract impact, tests, assumptions, and limitations.
