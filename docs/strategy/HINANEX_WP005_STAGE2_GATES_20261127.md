## 2. 限定再監査と正式接続の受入軸

| 項目 | Cが反証する条件・必要な試験 |
| --- | --- |
| B-P1-01 | 通常変更の失効ACK前に確定しない。安全側遷移でACKを待たない。認識・ラッチ・ACKが競合する順序と旧状態の復活を検証 |
| B-P1-02 | 失効未確認の旧bindingがある状態で新bindingを成立させない。管理された終了証拠が欠けた場合と復帰時を検証 |
| B-P1-03 | 遅延Grantが旧世代や元期限を越えて有効化しない。受理済み／未受理・再bindingの競合を区別 |
| B-P1-04 | D/Bの単調時計・相対速度・RTT・丸めを位置づけ、合成時刻および意味上の期限とLeaseを分離。時計不可信では再認可を拒否 |
| B-P1-05 | bootstrap trust root、起動元とサーバーの相互真正性、WSSの経路と脅威モデルが再現可能。偽起動元・照合失敗・切断時の閉鎖 |
| B-P1-06 | 通常稼働の事前定義、停止の独立観測、計測誤差、反証可能なFAIL条件を固定。約1,300msは採用済み保証値として扱わない |
| B-P2-01／02 | 操作Contractの確定原子性、重複Intent拒否、旧状態での確定拒否を追跡。原本文書とmanifestを固定して、再取得で異版を拒否 |

D側の内部仕様には、S0の明示DRILL・期限・generation、S1の合成比較と明示選択がある。Stage 2のJ02は有効なDRILL条件を確認し、J03はDの結果・理由を表示する。Bで再計算せず、 `UNKNOWN`、非一致、`NOT_EVALUATED` の差を保持する。J04のUI上の最大2件は一時的な比較状態。J05は別途承認した操作契約の下で本人の明示操作、比較2件への所属、最新generation、期限、再評価を確認する。旧MJ-01 revisionをDのgenerationに流用しない。STOP・失敗・期限切れ・地域変更・リセットで旧rows・比較・選択を消去し、`BLOCKED`または初期状態へ戻す。物理画面の停止中に有限時間で消去できる保証は設定しない。[D/S0](../../pipeline/docs/DRILL_SESSION_S0_20261113.md) · [D/S1比較](../../pipeline/docs/S1_SYNTHETIC_COMPARISON_V01.md) · [D/S1本人選択](../../pipeline/docs/S1_SYNTHETIC_REVIEW_SELECTION_V01.md)
