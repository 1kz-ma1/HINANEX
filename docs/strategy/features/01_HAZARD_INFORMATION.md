# F01 災害情報・ハザード閲覧（単独で使える機能）

- 状態: **PROPOSED UX SPEC**。既存の洪水レイヤーはCURRENT、地震・津波の新規レイヤーはFUTURE。
- 主な対象: E GIS（表示）／A（出典）／C（独立検証）／D（必要な正規化）。**一つのPRで領域を跨いで実装しない**。
- 目標: 施設を選ばなくても、ある場所・地域に関する公的な災害リスク情報を出典/想定条件/時点と一緒に理解できる。

## 使い方（独立した利用者体験）

1. 「災害情報」画面で、地域か地図上の地点を自分で選ぶ。GPSは任意で明示許可のときだけ使い、拒否しても地図タップ等で使える。
2. 利用できる災害種別（洪水から開始）を選ぶ。提供していない災害種別を「対応済み」と表示しない。
3. 公式のハザードレイヤーを表示。凡例と**何の値か**（最大浸水深想定、地震動予測確率、津波浸水想定など）・前提条件・更新/基準時点・原本の発行元・カバレッジを確認できる。
4. 施設情報へ進まなくても画面を閉じられる。将来F05から任意に施設情報を開けるようにする。

## CURRENT（既存資産、ただし完全受入の主張ではない）

- `gis/gis/` のLeaflet地図、公的洪水参照ラスタと地理院背景、地点クリック/許可したGPS、レイヤー切替、出典の表示。
- レイヤーの色は公式参照。**画像の色から独自に浸水深・施設の洪水適合性を断定しない**。
- 江戸川・新潟・名古屋などの元DデータやGSI参考探索は別系統。公式タイルが示す範囲を「全避難施設」へ転換しない。

## NEXT独立スライス案

- H-01: 洪水情報だけに集中できる独立操作入口を用意。既存GISのシナリオ/施設探索の要素をそのまま要求せず、表示される原本/種類/想定条件を確認する。
- H-02: レイヤーの「原本・想定条件・凡例・基準時点/不明・取得失敗・対応範囲」を分かりやすく説明。新Contract無しなら既存確認済み項目だけ出す。
- H-03: 1地点の**数値**を表示するなら、値と場所を同じ公的データ仕様に基づき取得できることを事前検証。ラスター色から値を推定しない。
- H-04: 地震はJ-SHISなどの**長期的な地震動予測**（震度実況ではない）、津波は行政の**指定想定条件の浸水範囲**（津波警報実況ではない）を別々のレイヤーとして検証後に追加。選定前に一次資料/版/利用規約/ライセンス/欠損範囲を確認。F04の時系列洪水と別物。

## 対象外・禁止

- アプリ独自の浸水・揺れ・津波の未来予測、危険度単一スコア、施設や建物の安全断定。
- ライブハザード実況／開設状況／安全経路の推定、未確認施設点の自動配置。
- 未取得・非対応地域を「災害なし」、現在地利用拒否を利用不可とする動作。

## 最小受入基準

- PC/スマホで施設操作なしに洪水の公式レイヤー・凡例/出典を辿れる。
- 地点の変更/地域変更/レイヤー切替で古い表示が残って「別地域の結果」と誤認されない。
- 通信障害、非対応、公式データ非掲載を区別し、利用者に説明。色・値・単位・確率期間を独自変換しない。
- 参考情報であることと公式発表の確認導線が残る。合成fixtureのUIテストと公式実データの独立検証は別々に記録。
