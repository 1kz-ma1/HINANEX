## 単独の利用体験

1. 端末に保存可能な範囲・容量・最終取得時点を表示する。
2. 本人が必要な参照情報を保存する範囲を選ぶ。PWA/Service Workerは別設計。
3. 通信不能時は保存済み情報であることと期限・欠損を明示し、外部公式情報への接続不能を説明する。

## 必要な入力・データ・確認事項

公式再配布/オフライン保存の許諾、個別データ版、TTL、端末容量、更新失敗、削除手順。

## 安全・プライバシーの境界

キャッシュから「今開設している避難所」「警報なし」を示さない。静的サイトで動いてもオフライン保証とは言わない。位置・個人設定と公式データのキャッシュを分離。

## 検証の最低条件
