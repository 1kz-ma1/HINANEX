# F12 よくいる地域の切替・地点検索

- **Status: FUTURE DESIGN / PROPOSED / 未実装**。2026-10-30の候補仕様。既存の部分機能があっても、本書に書いたユーザー体験が完成済みという意味ではない。
- **価値**：自宅周辺・学校など、複数の場所の情報へ素早く移動できる。
- **優先度（実装予約ではない）**：P1（地域切替の簡便化）／P2（複数保存・住所検索）。優先度の正本は [機能優先度マスター](FEATURE_PRIORITY_MASTER.md) を参照する。

## 単独の利用体験

1. 自治体/地域名から場所を検索し、地図タップでも選択できる。
2. 地域の複数登録は任意。端末に保存する場合は市区町村レベルから開始する。
3. GPS拒否時・住所検索失敗時も手動選択を維持する。

## 必要な入力・データ・確認事項

公式自治体コード/地名辞書、検索出典/利用制約、保存可否。住所ジオコーディングは第三者送信や精度の別審査を要する。

## 安全・プライバシーの境界

精密な自宅位置/通学先住所を勝手に保存しない。候補位置を正式な施設・避難経路の承認位置へ流用しない。
