## 単独の利用体験

1. 利用者が出発点と対象施設を明示選択する。
2. 公開可能な、検証済みの地点だけを参考終点に使う。
3. 経路サービスや地図を出典・第三者送信の同意とともに開く。移動手段と通信失敗を明示する。

## 必要な入力・データ・確認事項

出発点同意、行き先の正式な位置根拠/受入範囲、経路事業者規約、移動手段、マップ/外部APIの制限。

## 安全・プライバシーの境界

直線最短・徒歩所要時間・道路が描かれた事実から災害時の通行可能性や避難可否を保証しない。未承認の入口や敷地点は終点にしない。
