# F06 公式警報・避難情報へのアクセス

- **Status: PARTIALLY_MERGED**。2026-11-04にF06-L01の静的公式リンク導線をmain統合。ライブ警報取得・通知・公式発表内容の表示は**FUTURE/HOLD**。元の候補仕様は将来範囲を含み、実装済み全機能を表すものではない。
- **価値**：自治体・気象庁等の災害情報の公式発表へ素早く到達できる。
- **優先度（実装予約ではない）**：P1（リンクのみ）／P3（ライブ取得・通知）。優先度の正本は [機能優先度マスター](FEATURE_PRIORITY_MASTER.md) を参照する。

## 単独の利用体験

1. 選択地域の公的情報の種類と配信元を表示する。
2. 静的サイト段階では正本の公式サイトへのリンクを開く。取得の失敗やリンク切れは未取得と表示する。
3. 将来、許諾・更新保証・障害対策を確認した公式データに限り、更新時点つきで情報を表示する。

## 必要な入力・データ・確認事項

自治体/気象庁等の公式URL、発表区分・地域単位・時刻定義、配信規約、API障害状態。実時間連携は未調査。

## 安全・プライバシーの境界

ハザード想定と現在の警報を混同しない。取得成功を「現時点で安全」とせず、通信断時に過去情報を現在情報へ昇格しない。プッシュ通知は別の権限・配信信頼性レビュー後。

## 最初の実装スライス（F06-L01／限定実装済み）

既存GISの手動選択地域（江戸川区・新潟市・名古屋市）から公式サイトへ到達できる静的リンクUIを統合済み。F03の保存地域との連携は未実装。偽の最新状況表示はしない。

## 依存関係／着手ゲート

F01（地域の表示文脈）、F03（任意保存地域）。ライブ配信段階では公式API・運用監査。

共通で、実装前に最新版のmainと `AGENTS.md`、領域別契約、出典/ライセンス、既存コード・テストを確認すること。新規Contractは必要になるまで定義しない。実装は独立した小PR、公式の安全判断は人間Cレビューと公開審査を別に要する。未取得・UNKNOWN・通信失敗は推測で埋めない。

## 検証の最低条件

- 成功：保存地域または手選択地域から公式サイトへ到達できる静的リンクUI。偽の最新状況表示をしない。
- 未確認/対象外：不足情報・非対応地域/状態を「存在しない」「安全」と誤認させない。
- 失敗：通信/保存/権限/版不一致で、古い内容を最新・承認済みと表示しない。
- 合成fixtureのPASS、PC/スマホ操作、公式一次資料のC独立受入、運営の公開可否は**異なるゲート**。
