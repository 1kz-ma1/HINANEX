## 非表示・ネットワーク障害などの代替手順

- 地図タイルが一部欠けた場合：**洪水レイヤーの配信範囲・欠損は独立の問題**と説明し、D/GSI証跡がある場所の情報・名古屋市一覧を続ける。洪水タイルの未配信を安全域扱いしない。
- 配信・オフラインで `gsi_verified_tiles` が未配信なら：C未検証と表示されたままデモを止め、**事前録画した検証済み9/9の実機映像**を利用する。ダミーの紫サイトや偽造した検証成功を作らない。
- D runtime JSONが失われた場合：自動再生成で証拠を上書きせず、`inspect_local_region_exports.js` の表示を記録したうえで、**確認済みの事前録画**で説明する。
- 発表練習では「現在できる：公式掲載情報の根拠付き閲覧」「将来構想：危険度評価・安全な経路・地域／災害種別の拡張」を明確に分ける。安全性、開設、リアルタイム対応、全国適用を未検証のまま約束しない。

## 90秒ライブデモとガイド付きプレビューの違い

現在の `gis/gis/js/guided_tour.js` は江戸川区→新潟市→名古屋市を**各6.5秒**で自動案内する短い閲覧プレビューです。地図の移動と座標有無を紹介しますが、上記の**90秒ライブ操作の代わりではありません**。GSI地点の照合、洪水ラスタの説明、地図のクラスタクリック、公式資料の検証まで自動承認するものではありません。

- 90秒ライブ：上記の時刻表を優先。画面操作は人間が実行し、発表者が説明する。時間は本番と同じ機材で測る。
- 短いガイド：時間が押した場合の**既存UIによる補助**であり、「90秒通し実機テストPASS」とは別扱い。手動Next/一時停止/Stopでいつでも戻す。
- 外部GSI検証済みJSONが欠ける場合：紫の公式掲載地点を**作らない**。その場では根拠未検証を説明し、CのオフラインT0証拠シートへ切り替える。ただし歴史的T0は現在の安全な避難所・開設・災害予測の証明ではない。
- D地域JSONが欠ける場合：施設0件と断定しない。Eの未取得表示を見せるか、以前に**同じデータ版で記録した**実機映像へ切り替える。新しいデータと一致したふりをしない。
- 洪水ラスタのタイルが欠ける場合：「浸水なし」ではなく配信／描画未確認と明示する。録画に置き換えても現在の安全性は証明しない。

補助UI・欠損ソースの回帰テストはE専用 `gis/tests/demo_20261022_browser_smoke.js`（共有CIから一時Render相当配布物で実行）。成功しても**90秒の人手計測、7分間通し発表、ブラウザ・ネットワーク・会場機材は別受入**とする。
