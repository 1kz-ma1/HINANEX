# HINANEX MAIN AUDIENCE DEMO — 江戸川区の2施設比較へ転換（2026-10-21）

## 決定
以前の検討で、周辺にある千葉県側のGSI紫ピンをメインで紹介するより、**江戸川区として収録した施設同士を地図上で比較する**デモを優先する方針を採用した。2026-10-21のユーザー確認を受けて、QR/共有入口のメイン動線をこの体験へ差し替える。

- 旧GSI洪水指定/掲載地点の独立検証機能、公式出典リンク、GSI/Dの区別は保持する。ただし旧GSIの4場面自動説明は「比較を始める」通常動線から外す。
- 既存D RegionExport `region.code=13123` `shelter_location` の `mappableRecords` を唯一の比較対象とする。最新データで正しく取得できる場合にだけ画面に一覧を出す。架空の施設、GeoJSON、住所補完、GSI/Dの住所による自動結合は禁止。
- 比較対象は取得データ上の施設であり「現時点で江戸川区が正式に開設している避難所」ではない。記録の地域コードに基づく表示は行政界内の全座標検証も意味しない。
- 本人がセレクトメニューで**異なる2つ**を選び、名称/住所/種別/区域/収容人数/元座標の存在/洪水Scenarioの状態・理由・Source URLを並べて見る。値なしを事実上の0・安全・閉鎖に読み替えない。文字は `textContent` で描画。
- 「2件を地図で見る」の**ユーザー操作時だけ**2つの元座標に `fitBounds`。GSI/千葉県側へ強制ズームしない。
- 比較中のA/B markerは元のD座標からのみ生成し、避難推奨順位を意味しない。
- 江戸川区は広域避難を原則とし、待避施設はやむを得ない際の緊急避難先という公式説明を併記。二つの資料間の自動施設同一性判定はしない。

## 既知の境界と自動停止
- D施設の洪水分類は `UNKNOWN` の場合そのまま表示。 `CANDIDATE` もそのまま安全認証にはしない。
- 取得できない、レコードが2件未満、両者同じID、地域が切替、未承認GSI資料を使う場合は比較不可。
- 生の地域施設レコードに記録された出典URLがある場合のみ安全なHTTPSリンクで表示。ソースがない場合はリンクを作らず「元データで未確認」。
- 未検証情報を条件にした推薦・ソート・自動経路、安全確定は行わない。
- 新旧プレゼンターは同時に実行しないことが望ましく、メイン共有CTAでは旧GSIを起動しない。既存のGSI presenterは従来機能として維持。

## 実行/受入
- `?demo=audience` のWelcome →「デモ開始」で江戸川区施設比較が起動。本人操作なしの自動GPS・自動再生なし。
- 1365px PC / 390pxモバイルのChromiumで、施設2件選択、属性・UNKNOWN比較、2件のみの地図移動、閉じる操作を確認する。
- 旧GSIソース検証のChromium経路は開発専用の明示起動で回帰確認する。Web上のGSI原本配信や正式A/C承認を証明するものではない。
- 実機Safariと聴衆への説明の分かりやすさは別途レビュー。

## 開発統合
- 変更はEの `gis/**` に限定。新しいPublic Contractは作らず既存のD adapterを使う。
- 最新mainと必須CI、E専用実ブラウザ受入が成功するまでmainへの統合はしない。
