# E: PCのGSI本番デモも上部案内中心にする（2026-10-20）

## CURRENT / 今回の変更対象
- ユーザーからのPC UX指摘：上部に案内があるのに画面右下のGSIデモカード（従来 `380px × 最大520px`）が大きく、Leaflet地図の理解を妨げる。
- PC幅（781px以上）でもスマホと同じ **上部の場面説明を唯一の常設デモ画面** とする。再生・一時停止、次の場面、任意の根拠詳細、閉じる操作を上部案内に集約。元の右下カードは既定で非表示。
- **根拠を見る** を押したときに限り、幅最大320px／高さ最大355pxか画面高さ43%以内の小さな右下パネルを開く。上部ボタンから戻せる。公式の属性（洪水 `disaster1=1`）、検証済みタイル数、元GeoJSONの出典リンク、選択した紫ピンの住所・trace、Dの洪水判定UNKNOWNは変更しない。
- 画面進行・シーン文言・4つの公式参照URL、GSIの厳密なタイル検証、選択した地図ピンで次に進む必須操作、出典不明時の fail-closed、別ソースGSI/Dの非同一性は一切変更しない。
- 公式GSI参照がないPCでも、大きなfallbackカードの代わりに上部の短い未検証案内を表示し、再生・次へ・根拠ボタンは使わせない。元の「未確認≠施設不存在」の文面と一次資料リンクは上部に残す。
- PCの説明文は「カードで確認」から「地図のピンで原文を確認」に修正（カードの常設表示を前提としない）。
- スマホ（780px以下）は **従来と同じ一枚の上部案内と2ボタン（再生/一時停止・閉じる）** を維持。PC専用の「次へ・根拠」は非表示とし、地図の紫ピンをタップする既存手順を維持。
- 既存GSI source-only比較機能 #277 の比較パネルはこの変更の対象外。今回の「根拠を見る」は**デモの詳細**であり、2地点比較ではない。
