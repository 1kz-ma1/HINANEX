# 江戸川区：待避施設・広域避難とGSIの意味を分けて伝えるデモ（Phase 1 / 2026-10-20）

## 目的と変更の根拠
ユーザー観察：江戸川区を選択したGSIデモで、実際の紫ピンが千葉県側に見える。「江戸川区内には洪水対応の避難場所がない」と誤解させないため、**地域選択とGSIタイル探索は自治体境界による施設選別ではない**と、デモ内で明示する。

江戸川区の水害ハザードマップ（第2版、2025年7月公表）には以下が記載されている。
- 大規模水害時は、区外の親戚・知人宅、勤務先、宿泊施設等を利用する**早期の広域避難**を案内している。区外の公的広域避難先施設は混雑の可能性があり、250万人規模の一斉広域避難は混雑・渋滞の要因となると注意している。https://www.city.edogawa.tokyo.jp/e007/bosaianzen/bosai/kanrenmap/hazardmap/koikihinan.html
- 「**待避施設**」は、避難の時間がない場合や避難が困難など、やむを得ないときに**緊急避難**する施設。学校等の掲載・使用可能階数は、通常の避難先推奨、当日の開設、避難人数、長期滞在の安全性を証明しない。https://www.city.edogawa.tokyo.jp/e007/bosaianzen/bosai/kanrenmap/hazardmap/ikinaihinan.html
- 広域避難が難しい場合などを含め、避難の選択は状況に応じた公式フローに従い、一律に「区内の学校へ行くべきでない」とは表示しない。https://www.city.edogawa.tokyo.jp/e007/bosaianzen/bosai/kanrenmap/hazardmap/suigaihinan.html

**注意**：上記は自治体が公開している**一般的な避難方針の説明**。予測災害条件に依存し、現在の避難情報や施設の開設有無を判定するものではない。区の施設一覧の名称／住所をD/GSIの個別施設に「同一地点」と結合しない。

## 現行実装：既存 MAIN GSI の4場面を再構成
既存の43秒＋実ピン選択待ちのシーケンス・内部検証は維持する。

| 場面 | 見せる意味 | 一次資料へリンク |
|---|---|---|
| 1 | **近くの学校＝最初の避難先とは限らない**。大規模水害では早期の広域避難を案内 | 区「広域避難」 |
| 2 | **待避施設≠GSI skhb01 洪水指定緊急避難場所**。紫は検証済み周辺タイルの最大5地点。千葉県側を含み得る／区内件数ではない | 区「待避施設」 |
| 3 | 実際の紫ピンを**本人がクリックして**元GSI掲載地点・原文を確認する。開設・混雑・安全は別情報 | 国土地理院「指定緊急避難場所」 |
| 4 | **掲載地点・D未判定・区の避難方針・開設状況・混雑・経路を結合しない**。現在の避難推奨は行わない | 区「水害時の避難フロー」 |

- 対象は `gis/gis/js/gsi_flood_demo.js` のタイトル・短文および**直接一次資料への固定リンク**。URLは表示時の取得結果を装わず、自治体政策の資料を別途開くためのもの。
- `?demo=audience` のWelcomeも「待避施設／広域避難の違い」「周辺県ピンの可能性」を説明する。観客の同意前にアニメを自動開始しない。
- `max-width:780px` は**上部の場面別説明カードだけ**。新しい大型カードや地図を覆う学習用オーバーレイは作らない。公式資料リンクだけは上部からタップで外部タブに開ける。Desktopは元の詳細カード＋上部説明を維持。
- 実際のGSIタイルが検証できないとき**fail-closed**：架空の紫ピンを描かず、デモ再生を停止し、未確認と理由を表示する。区の公式方針リンクのみ提供する。
- 個々の待避施設の区内地図ピンや使用可能階数の読み込み・GSIマーカーへの変換、動的な「最寄り／定員／混雑」の推薦・開設ステータス付与は今回**実装しない**。これらは、別の公式原本レビュー／定義・識別・用途／データ範囲と認証の承認が必要。
