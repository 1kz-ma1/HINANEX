# 10月22日 GIS内で見る3ケース検証過程デモ（E）

入口：GISの「場面 → 発表用ガイド付きデモ → 地図上で3つの検証パターンを再生」。

**別タブではなくGIS内の説明用ビュー**を開く。地図の視点・選択地域・D RegionExport・GSI・洪水タイル・施設の判定は変更しない。GISはキャンバス背景のまま。旧3地域ツアーは補助機能として維持し、開始時には停止する。

C正本 `/evidence/2019_edogawa_evidence_cases.json`（C #226、shared #227）から3ケースを読む。ケースの原文とC statusを画面再生によって変更しない。元の独立B説明ページ（#228）は「詳しい検証資料を見る」に残す。

- ケース1：T0の事後原本と抽出データの**機械的整合**。実災害の予測MATCHではない。
- ケース2：2019年台風19号・江戸川区の205/11の当日避難建物不明。T1=NOT_EVALUABLE、建物pair=0、**予測ABSTAINが成功したという意味ではない**。
- ケース3：Cの**合成負系テスト**（夜間明細消去・校舎住所から避難先を推測）が異常な変換を拒否。実災害の予測MISMATCHではない。

4工程（資料→抽出→C監査→検証の結論）を各ケースで段階的に見せる。15秒導入と各25秒（6/6/6/7秒）で合計90秒。自動再生、一時停止/再開、手動前後・ケース切替、最初から、Escで終了。資料/監査Runリンクを明示。タブ非表示や地図操作で再生停止。元の地図ツアー終了・再開時にGISカメラ操作をしない。

データHTTPエラー/契約や出典の不整合/古いリクエスト応答はfail-closedで説明を表示しない。Cの人手による2019 as-of承認・T1/T2予測と安全認定は未実証。
