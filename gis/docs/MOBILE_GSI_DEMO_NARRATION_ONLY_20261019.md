# MAIN GSI DEMO：スマホは上部の場面別説明カードのみ（2026-10-19）

## 背景と要求
実機スマホでは、従来のGSI発表デモ下部カードが地図の大部分を占め、対象の紫ピンと場面ごとの説明を同時に追いにくい。今回のユーザー判断：**モバイルでは右側カードの下部ドックを出さず、4タブ直下のコンパクトな「場面別説明カード」だけで案内する。** PCでは従来どおり右側のデータ・操作カードと上部説明バーを維持する。

## 実装方針（E/GIS内だけ）
- `max-width: 780px` では、既存 `#gsiFloodDemoPanel` は表示を完全に抑止（`display:none`）。**JSの状態管理／GSIの元データ照合・シーン遷移は既存のまま内部で動く**。上部 `#gsiDemoNarration` に現在の番号・見出し・短い説明・**再生/一時停止と閉じる**操作を置く。
- PCではモバイル操作をCSSで非表示にし、ソースや件数・住所・URL・再生操作を右側カードで引き続き表示。上部は説明だけにしてデスクトップを乱さない。
- 説明の背景はLeafletタップを妨げない（親 `pointer-events:none`、ボタンだけ `pointer-events:auto`）。操作ボタンは焦点移動可能、誤タップを避ける最低36pxのタッチ領域。モバイルでは表示されないデスクトップのカードへフォーカスしない／Tabのフォーカストラップをかけない。
- 4場面は既存の公式 `GSI_SKHB01_FLOOD` 検証済み原本だけを扱う。場面3は**ユーザー本人による実際の紫ピンタップを必須**にして、選択がなければシーンは止まる。位置や掲載施設を自動推測・選択しない。選択後は地図の既存のピン表示を案内し、隠した下部カードへ誘導しない。
- 公式GSIが取れない／検証できないとき、スマホの唯一の上部カードには**「公式データを確認できません」**と取得失敗の原因・未確認は「該当なし／安全」を意味しない注意書き、閉じる操作を表示。無根拠の場面別データ説明は表示しない。PCでは元のエラー／代替操作カードを維持。
- 地図の洪水タイル等の安全上の警告は非表示にせず、上部説明と重ならない場所へ移す。右カード非表示でもデモ外の地図メニューや通常の施設詳細・選択は存続する。表示上の地図ピンは安全・開設・避難推奨を示さない。

## 検証
- `node --test gis/tests/gsi_flood_demo.test.js` は、モバイルの停止/再生・終了・実ピン待ち・検証できないGSIの表示・デスクトップ原本カードを確認。
- `gis/tests/demo_20261022_browser_smoke.js` は、幅390pxで `#gsiFloodDemoPanel` の `display:none`、説明カードの4タブ直下配置、説明文の可読サイズ、カード外のマップ領域、停止・再開・閉じる操作、未検証GSIの正直な失敗表示を実ブラウザで検査。
- 必須GitHub Actions `test` とEの既存GIS回帰を確認。画面比率の違うiOS Safari（例390×844と360×740）および実ピン選択・画面回転・下部ナビ等については**別途実機QA**。CIの静的検証だけで「iPhone実機で再生成功」とは言わない。
