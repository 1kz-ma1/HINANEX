# GSI洪水指定デモ：2026-10-14実機スクリーンショット調査

実画面：選択地域は江戸川区だが、地図中心は西東京・神奈川方面。GSI公式データは「現在の地図中心付近では確認できない」となり、50秒デモが開始できず右側パネルが空白になった。

## Eの修正
- 選択地域のD RegionExportに**元座標が記録された実レコード**がある場合、明示的に選択した探索起点がなければ、その先頭レコードの元座標を**閲覧用の探索起点**とする。現在の地図中心を、地域に属する情報として推測しない。この地点は安全な避難先・当該GSI地点という意味ではない。
- デモ開始時にこの閲覧用元座標にフォーカスし、退出時には元の視点とGSI/D表示設定を復元。閲覧者が手動移動した場合はカメラを復元しない。
- Dの元座標すら取得できない場合は探索を中止。未確認GSIタイルのデータを一切生成せず、公式指定施設の「0件」「なし」とは見せない。
- GSI掲載データ未配信・未検証の場合には、停止理由と**明示的なユーザー操作でD施設の属性絞り込み52秒デモへ移動する**リンクを表示。Dフィルタを「GSI洪水指定」と偽装しない。

## 別担当/Sharedの未解決依存
Renderが公開するdeploy/dist生成器には、C承認と公式HTTPS byte-replayにより検証済みのGSI z10 JSONを配置する処理がない。公開用GSIタイルデータ自体もGit管理外。実データを用いた公式GSI 50秒デモが動作するには **A/Cの出典と再検証、Dのタイル配布物、Sharedデプロイの配信パス確認** が必要。元データやC受入証跡がない状態で偽のJSONをコミットしたり、出所未確認のGeoJSONを公式指定として表示してはいけない。

このE PRは回復可能なUXだけを扱い、CI/デプロイ/公式データを勝手に書き換えない。CI greenとRender実機でGSIが動いたことは別。
